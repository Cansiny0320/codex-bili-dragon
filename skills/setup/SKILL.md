# 初始化 B 站小白龙

1. 调用 `dragon_control` 的 `status` 查看后台。用户要求启动或首次设置时调用 `start`，再调用 `dragon_open` 打开管理页。启动本地服务不代表用户已经开启自动活动或任何 B 站发送权限。
2. 检查 `dragon_status` 中的账号配置、作息和暂停状态。缺少 B 站凭据时，引导用户在管理页「账号连接」使用 B 站 App 扫码并在手机上确认；手动 Cookie 位于高级选项。不要求在聊天中粘贴 Cookie，也不读取凭据文件。
3. Codex 未登录或不可用时，在本插件根目录运行 `node dist/runtime/cli.js doctor`；遵循实际输出帮助用户完成官方客户端登录，不复制 Codex 登录令牌。
4. 用户在管理页设置兴趣、活动时间和权限后，可以自行启用活动。不要替用户开启评论、私信、弹幕或分享开关，不自动运行「探索一次」。
5. 用户要求暂停时调用 `dragon_control` 的 `pause`；要求关闭后台时调用 `stop`。不要使用按进程名批量结束进程的命令。

原生入口依赖 Codex 桌面宿主支持 MCP Apps Extensions。工具尚未刷新时检查插件启用状态，并引导用户在插件详情页「管理 → 重新加载」；不要伪称已显示侧边栏。安装与升级见包内 `INSTALL.md`。管理页关闭不会停止后台；电脑休眠时不能保证持续运行。
