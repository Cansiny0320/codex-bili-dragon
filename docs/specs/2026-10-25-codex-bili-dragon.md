# Codex Bili Dragon 设计（已批准）

日期：2026-10-25。用户批准原仓库复刻方案，要求更换鲸鱼命名，并明确在 D:/code 下开发和创建 GitHub 公开仓库。

## 目标

使用固定版本的 B 站工具集合（v0.4.6，commit 3e11454a5961300aa7094df0f08e630bd39999dd）制作 Codex 本地插件。产品名 Codex Bili Dragon，中文 B 站小白龙；源代码位置 D:/code/codex-bili-dragon。命名取自中文社区 GPT 白龙/龙娘二创意象；无官方关联，不分发现成角色图片。

## 架构与行为

- 保留上游 B 站阅读、字幕、热评、弹幕和 ffmpeg 抽帧工具。固定来源与 MIT 署名，改动记录在 UPSTREAM.md。
- 新增 MCP + Skill 入口；本地后台负责持久作息、评论/私信/直播监听及任务队列，官方 Codex app-server 驱动专属会话。仅有消息或到期活动才调用模型。用户显式启动后台，不创建开机任务。
- 可配置人设、兴趣、时区与作息；保留随机唤醒/跳过、两本日记、分享限额、冷却、反馈和去重。
- 主人身份通过 B 站 UID 匹配；陌生人评论回复须保存草稿、经用户审核再发送。私信仅给主人并遵循上游互关约束。各写通道默认关闭。
- 本地设置页提供账号凭据输入、设置、人设、日记、草稿审核、任务/故障状态。仅绑定回环地址，写请求要求会话令牌与来源校验；凭据不返回给页面或模型。
- 数据默认在项目 data/，可使用 BILI_DRAGON_DATA 指定独立绝对路径；不读取 DSH 数据。公开仓库排除 data/、凭据、日记、日志、缓存、依赖和本机绝对路径配置。
- 仅使用官方 Codex 登录，由 Codex 维护 OAuth。寻找兼容的桌面运行时，兼容性失败清楚报错；不修改全局 Codex 配置。模型使用账户可用配置，不写死新模型或套餐承诺。

## 状态与失败语义

- 作息与消息入队持久化，唯一键去重；同一后台单实例，同一会话串行运行。
- 派发前记录 running；中断/结果不明转为 needs-review，禁止自动重新发送。发送工具另有操作账本及上游跨进程限额/退避保护。
- 跨午夜窗口按配置时区和窗口起始日期计算；错过的旧窗口不集中补发。设置变化不清除已完成记录。
- 无字幕、抽帧失败、未读取图片时明确证据范围，不能声称完整看过视频。
- 登录失效/限流停止当前工作并报告；模型额度耗尽或后台关闭不会保证离线持续运行。

## 验收

Node 离线测试覆盖时区和跨日、调度去重、并发/重启、未知结果、草稿审核与写开关、凭据隐藏及数据路径隔离、真实 MCP stdio 工具发现、模拟 app-server 消息与回合、HTTP 页面/CSRF。原版相关回归测试在独立临时目录运行。后台与页面实际启动验证，无真实鼠标/键盘输入。B 站账号和真实写操作未配置前只做匿名读取或模拟，不发送真实评论/私信。

## 发布与回滚

用户授权公开 GitHub 仓库。首次发布前做文件清单与秘密扫描，提交仅本项目。撤回本地接入可卸载 MCP/插件并停止后台；数据独立保留。无自动启动、无付费资源创建。
