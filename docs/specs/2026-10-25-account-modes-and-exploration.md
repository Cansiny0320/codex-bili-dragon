# 账号双模式与登录、探索修复

用户已批准 2026-10-25 本机会话中的双模式方案，并授权修复首页账号信息、探索无产出及默认私信权限。

## 已批准行为

- 单号模式使用登录账号作为主人，自动取得 UID、昵称；保留探索、双日记及互动审核。禁止给自己私信和主动分享。
- 双号模式由小白龙使用登录账号，主人 UID、称呼单独填写。给主人发送仍受通道权限、分享开关和既有审核规则约束。
- 旧配置首次验证登录身份后，主人 UID 与登录 UID 不同则保留为双号，相同或未填则转为单号；已有明确模式不重新推断。
- 切换模式、主人或登录账号前暂停活动，作废旧待执行任务和待发草稿；保留历史记录、已发送记录及不确定结果，不自动重发。
- 新配置默认开启发送私信，评论及直播弹幕仍关闭；已保存的明确权限不覆盖。单号模式仍禁止向自身发信。
- 首页显示经过验证的登录账号头像、昵称、UID；不再用主人 UID 代替登录账号。
- 恢复 Codex 动态工具依赖的本地 Code Mode 运行环境，继续禁用 Shell、文件操作、浏览器、其他插件及 MCP。
- 浏览任务不能仅因模型回合 completed 就记作成功；未写入日记时保留失败原因供用户核查。成功任务显示产出，失败不自动重试。

## 压力测试结论

登录账号是执行身份，主人是接收身份；单号中二者相同，不能发送给自身。旧配置不得只按新增字段默认值覆盖既有独立主人。身份变化必须覆盖已排队和执行中的任务、草稿及迟到的结果。任何新发送都重新检查当前模式、接收人和通道权限；不会启用自动运行或额外的分享功能。

首页、账号页和实际发送使用同一服务端身份。公开身份资料可以保存本机，Cookie 不出现在状态、日志或 UI 回读中。网络失败不冒充未登录或已连接。

## 范围与回滚

仅修改本仓库和已授权本机插件安装；参考会话和 `D:/code/bili-whale-web` 只读。保留用户数据，不 commit、push、发布或发送真实消息。回滚可重新安装 0.4.0，并使用升级前的本机数据备份；新增模式字段需随回滚配置移除，避免旧版严格 schema 拒绝。
