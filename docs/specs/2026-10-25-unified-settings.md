# 操作权限统一设置与模型选择

状态：用户已于 2026-10-25 明确批准。

## 目标与已批准行为

- 在「操作权限」统一管理互动权限、主动分享、消息监听、自动更新、模型和思考深度；监听从「活动时间」移出，自动更新和模型从「账号连接」移出。保留原有页面布局语言，不重新设计其他页面。
- 兴趣关键词默认空白；默认人设不预设技术、小制作等题材偏好，保留说话风格和真实性要求。已保存的自定义兴趣、人设及显式开关值不被升级重置。
- 新配置默认开启主动分享（私信）、私信监听、自动更新。单号模式仍不能主动私信分享给自己；活动总开关继续默认关闭。
- 主动分享设置移除人为输入上下限与对应后端硬上限；评分为有限数值，次数和天数保留合法整数校验。用户配置的每日次数、每轮一次、发送去重及平台约束保持有效。
- 模型选择默认跟随 Codex 配置；选项来自当前 Codex 的 model/list，思考深度随所选模型的 supportedReasoningEfforts 联动。不硬编码模型列表。
- 保存模型配置不打断正在执行的任务；下一次任务读取最新模型和深度。切回默认必须恢复实际默认值，不能沿用先前的会话覆盖参数。不可用模型和不支持的深度明确报错，不偷偷替换。
- 模型列表按需加载并复用短期缓存及并发请求，不放入管理页五秒状态轮询；临时查询连接在结束后关闭。

## 当前安装

仅同步用户明确要求的已有设置：清除仍等于旧预设的兴趣、开启私信监听、保留已开启分享与自动更新；不启用活动总开关，不重置用户自定义项。新界面和模型功能需要后续安装新版本，本次不发布或替换安装缓存。

## 验收

1. 默认值正确，已保存配置不被意外重置。
2. 大于旧上限的分享次数与天数能保存并重载；无效数值拒绝；实际发送仍执行配置配额。
3. 只有操作权限页展示上述开关和选择器；桌面及窄屏可用。
4. 模型列表分页、失败、默认选项和深度联动正确；Web 和 MCP 管理页均可调用。
5. 复用同一会话时，下一任务模型/深度更新；切回默认、重启恢复、错误组合都有回归测试。

## 边界

MCP 多进程问题只做只读诊断，不改变连接架构、终止现有进程或修改 Codex 配置。无 commit、push、发布、安装授权。新增配置/API 会触发更新兼容性检查，升级时需重新加载插件工具。
