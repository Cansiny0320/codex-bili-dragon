# 小白龙人设与自主行为补全

用户已批准聊天中的行为方案，并明确采用修订后的直接、自然的表达风格：具体说事，允许短评，不刻意制造转折、感悟、情绪或固定口头禅。此文忠实记录已批准内容。

## 目标与行为

- 每轮先读取当前人设、近期双日记、偏好记录和真实互动；沿用作息、随机唤醒与跳过概率。
- 在 night.maxVideos 上限内初筛，默认 5 条；看兴趣、内容质量和讨论价值，播放量仅作参考。深读其中 2–3 条，也允许不足或没有合适内容；按证据需要读字幕、评论和抽帧。
- 比较候选后只考虑本轮最值得分享的一条，也可以不分享。后端将每轮最多一次分享尝试与持久发送账本关联，失败或结果未知不得换视频重发。保留评分阈值、额度、冷却、单号限制与身份核验。
- 接回收藏工具：独立权限默认关闭。开启后仅收藏实际读取过、三个月后仍值得重看且能说清用途的内容；同类比较、每日最多 3 条、同视频 30 天去重沿用上游。未确认写入不自动重试。
- 补齐反馈采集：在已启用的评论监听范围内读取真实回复和收到的赞；沿用私信/直播收件身份核验。按主人 UID 与事件标识去重，使用事件实际时间。采集失败为未知，不冒充没有反馈，也不更新最后互动时间。
- 区分明确表达、暂时推测与小白龙自己的兴趣，记录来源。点赞只能支持推测；没有回复不代表不喜欢。学习记录不改写用户设置的兴趣，不把分析术语写进日记正文。
- 继续按已配置阈值减少长期无反馈时的分享；读取未知不应被解释为关系变化。没有分享也继续写日记，主人回来时自然接话，不催促、不埋怨。
- 收尾复查已启用通道的新消息与反馈，避免额外高频轮询；不重复回复同一事件。

## 人设与文风

默认保留小白龙/我/你/给你的信。有好奇心，喜欢技术、小制作、讲清楚的知识和实际尝试；有自己的判断，能改口、能觉得一般。熟悉后可以轻轻吐槽，不强行卖萌、不堆语气词、不虚构现实经历或共同回忆。

分享像顺手发给熟人的一句话，讲具体细节；给你的信写想聊的内容，长短随内容；内心日记允许直接说哪里一般、哪里没懂、下次想找什么。不要每篇都表现得有趣，不写任务汇报、偏好分析报告或情绪总结。证据、反馈来源和学习备注保存到结构化字段，不出现在两份正文中。

旧配置中与旧默认正文完全相同的内容迁移到新默认；自定义正文、空正文、名字、称呼、兴趣、历史日记及明确权限不覆盖。

## 实现边界

沿用现有 Codex app-server、受控 dragon_* 工具、JSON 存储和管理页。仅新增必要收藏权限，不重设计 UI。提示词和人设集中组织，当前人设每轮生效；动态工具合同改变时建立新的专属后台会话，旧会话和本地记录保留。

学习备注随日记保存为可选字段，区分明确偏好、推测、自身兴趣与后续选题；明确偏好必须引用真实主人文字事件。旧日记可继续读取。模型任务上下文使用近期内容和最近学习备注，完整历史继续保留供管理页查看。

用户随后明确授权完成后 push 到 GitHub、发布新 Release 并更新插件市场。本次以 v0.8.0 发布，将 main 中的预构建插件同步到新版本；核验远端提交、CI 与发布下载包。不修改正在运行的插件缓存，不发送真实评论/私信或执行真实收藏；行为试跑使用隔离目录及固定素材。

## 验收与回滚

测试必须覆盖原始默认迁移与自定义保留、反馈身份/去重/失败、收藏权限和写入端点、每轮分享并发与失败重试限制、旧会话工具升级、新人设每轮注入、旧日记兼容。固定素材试跑检查具体表达、无合适内容不分享、纠正后调整与正文不混入学习记录。自动测试不能保证文风，需要审阅实际试跑文本。

回滚为撤回本次源文件并重建；新增权限和日记字段需在降级到严格旧 schema 前从备份恢复。验证使用临时数据，不迁移或改写用户运行中的数据。
