## 验证命令及副作用

- `pnpm check`：只读格式/lint/类型及项目检查；先确认当前脚本不带 fix。
- `pnpm test`：使用临时目录和模拟上游，不连接真实账号。
- `pnpm build`：写入 `dist/`，为 MCP 和界面测试提供当前构建。
- `pnpm test:ui`：headless Edge，不注入桌面输入；生成 `work/` 截图。
- `pnpm package`、`pnpm test:package`：生成 ZIP，并解压到隔离临时目录验证。
- 安装使用既有官方 CLI 流程。真实二维码生成及未扫码状态可独立检查；手机登录需要用户本人扫码确认。

## 风险与回滚

B 站 Web 登录接口可能变动，保留高级 Cookie 入口；不新增自动续期。登录会话只在内存短期保留，后台重启后重新扫码。失败不覆盖旧凭据；数据格式保持兼容。可停止新版后台并重新安装保留的 0.3.1 安装包，再从管理菜单重新加载。只修改本任务文件，保留当前工作区其他改动，不做 Git 收尾。
